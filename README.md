## 🤖 Overview

An open-source attempt to create a cyber companion — a monorepo with 45+ packages spanning web, desktop (Electron), iOS (Swift), Minecraft bot, Twitter/Telegram services, and a VS Code extension.

---

## 🛠️ Architecture

```mermaid
flowchart TD
    A[Monorepo\nTurbo + pnpm] --> B[Web App\nVue + TypeScript]
    A --> C[Desktop\nElectron + Tamagotchi]
    A --> D[iOS\nSwift / Pocket]
    A --> E[Services]
    E --> F[Minecraft Bot\nmineflayer]
    E --> G[Twitter Service]
    E --> H[Telegram Bot]
    A --> I[VS Code Extension]
    A --> J[Docs Site]
```
